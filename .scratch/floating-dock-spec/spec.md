# Spec: 澄清问答底部常驻悬浮响应条（Floating Clarification Dock）

Triage Label: `ready-for-agent`

## Problem Statement

在涉及长文本、数据大表或复杂子智能体执行链的长对话场景下，大模型触发 `AskUserQuestion` 澄清提问后，用户往往需要**向上滚动屏幕去复核上文中的数据表格、业务指标或执行日志**。

在此场景下，位于消息流底部的澄清卡片会被滚出可视区域之外。尽管消息流内部已具备微光边框和子智能体定位按钮，但在**聊天窗口主视口底部（输入框上方）缺乏持续常驻的状态感知与一键回跳入口**，容易导致用户误以为生成停滞或迷失表单位置。

---

## Solution

在聊天视口底部（输入框上方）实现一个轻量、优雅的**常驻悬浮响应条（Floating Clarification Dock）**：

1. **纯前端响应式生命周期（Pure Frontend Reactive Lifecycle）**：
   - 严格基于前端 Store 中的当前会话流式状态（`isAwaitingClarification` 为真且未完成提交时激活）；
   - 提交成功、恢复生成或生成中止时，通过平滑过渡动画自动淡出收起，不产生任何视觉残留；
   - **0 后端改造、0 数据库改动、0 API 契约变更**。
2. **动态提问者身份与微光状态感知**：
   - 动态识别提问者身份（如 `🤖 SQL数据专家` 或 `智能助手`），展示文案：`🤖 SQL数据专家 正在等待您的确认参数...`；
   - 搭配呼吸蓝色脉冲微光点，向用户清晰传达“当前系统正处于人机协同挂起阶段”。
3. **一键平滑滚动与自动聚焦（One-Click Focus）**：
   - 悬浮条右侧提供醒目的 **【👇 前往填写】** 按钮；
   - 点击后，聊天主视口平滑滚动并自动将焦点（`focus()`）定位到底部澄清卡片的首个输入框或选项区域。

---

## User Stories

1. As a 业务分析人员, I want 在向上滚动翻阅长数据表格时，底部输入框上方始终有一条清晰的悬浮提示条, so that 我时刻清楚大模型正在等待我的参数输入。
2. As a 业务分析人员, I want 在悬浮提示条上直接看到是哪一个智能体在等待我（如 SQL数据专家）, so that 我清楚当前正在处理哪一个环节的业务上下文。
3. As a 业务分析人员, I want 点击悬浮条上的“前往填写”按钮一键滚回澄清卡片并自动聚焦输入框, so that 我无需手动费力向下拖动滚动条。
4. As a 业务分析人员, I want 在我点击“确认并恢复生成”或主动“停止生成”后，悬浮条自动平滑消失, so that 界面恢复常规聊天流态，不产生多余视觉干扰。
5. As a 开发者, I want 悬浮条组件与现有 Pinia Store 和澄清卡片松耦合, so that 架构清晰可维护且不引入任何额外的全局副作用。

---

## Implementation Decisions

1. **组件层级与挂载位置**
   - 挂载于聊天主视口底部与输入框容器之间的交互过渡层（或作为独立浮层组件嵌入）；
   - 使用 Vue3 `<Transition name="slide-fade">` 实现优雅的上下滑入与淡出动效。
2. **状态与角色数据源复用**
   - 直接复用 Pinia `messagesStore` 与 `useChatStream` 中的活跃流式消息上下文；
   - 提问者角色标题复用现有的统一映射逻辑，保证全局文案完全一致。
3. **视口滚动与焦点捕获**
   - 封装可复用的滚动聚焦函数，精确定位至澄清卡片容器；
   - 自动检测并聚焦首个可见的 `textarea` 或首个可选选项。

---

## Testing Decisions

### 良好测试的标准
- 验证在挂起等待澄清期间（`hasQuestions && !isQuestionSubmitted`），悬浮条正确渲染并显示对应智能体角色名；
- 验证点击“前往填写”时触发平滑滚动行为并成功触发聚焦事件；
- 验证提交后或会话切换时，悬浮条立即销毁并淡出。

### 重点测试范围
- `FloatingClarificationDock.vue`（或对应宿主组件）的响应式挂载与生命周期；
- 前端 `npm run build:check`（TypeScript 类型与模板编译）。

---

## Out of Scope

- 模态居中弹窗（避免遮挡上下文数据）；
- 后端数据表与持久化接口改造（保持纯前端轻量化）。

---

## Further Notes

- 悬浮条采用半透明磨砂玻璃质感（`backdrop-blur-md bg-blue-50/90`），视觉风格与现代设计系统高度融合。
