## 1. 项目概述

### 1.1 项目简介

Research Agent 是一个基于 LangChain 的大模型聊天应用，支持多会话管理、流式输出、工具调用和状态持久化。

### 1.2 技术栈

| 层级 | 技术 | 版本 | 用途 |
|------|------|------|------|
| **后端框架** | FastAPI | 最新 | 高性能异步 Web 框架 |
| **ORM** | SQLAlchemy | 2.0+ | Python ORM |
| **数据库** | PostgreSQL | 14+ | 关系型数据库 |
| **LLM 框架** | LangChain | 1.2+ | LLM 应用开发 |
| **状态管理** | PostgresSaver | 3.0.2 | Agent 状态持久化 |
| **连接池** | psycopg_pool | 最新 | PostgreSQL 连接池 |
| **前端框架** | Vue 3 | 3.4+ | 渐进式 JavaScript 框架 |
| **类型系统** | TypeScript | 5.3+ | 类型安全 |
| **状态管理** | Pinia | 2.1+ | Vue 状态管理 |
| **构建工具** | Vite | 最新 | 前端构建工具 |
| **CSS 框架** | Tailwind CSS | 3.4+ | 工具优先的 CSS 框架 |

### 1.3 核心特性

- **多会话管理** - 支持创建、删除、切换聊天会话
- **流式/非流式输出** - SSE 实时流式响应
- **工具调用** - 集成 arXiv 论文搜索
- **状态持久化** - PostgresSaver 自动管理 Agent 状态
- **自动摘要** - SummarizationMiddleware 压缩长对话
- **前后端分离** - RESTful API + SPA

### 2.2 设计原则

#### 2.2.1 关注点分离 (Separation of Concerns)

- **API 层**：只负责 HTTP 请求/响应处理，不包含业务逻辑
- **CRUD 层**：封装数据库操作，提供可复用的业务函数
- **Service 层**：处理复杂的业务逻辑（如 Agent 调用）
- **Model 层**：定义数据结构，不包含业务逻辑

#### 2.2.2 单一职责原则 (Single Responsibility Principle)

每个模块只负责一个功能：
- `api.py` - 路由定义
- `crud.py` - 数据库操作
- `models.py` - 数据模型
- `schemas.py` - 数据验证
- `services.py` - Agent 服务

#### 2.2.3 依赖注入 (Dependency Injection)

使用 FastAPI 的 `Depends` 实现依赖注入：

```python
@router.get("/sessions/{session_id}")
def get_session_endpoint(
    session_id: str,
    db: Session = Depends(get_db)  # ← 依赖注入
):
    return get_session(db, session_id)
```

#### 2.2.4 混合存储模式 (Hybrid Storage Pattern)

**业务数据** + **状态数据** 分离存储：

| 存储类型 | 表结构 | 用途 | 管理方式 |
|---------|-------|------|---------|
| **业务数据** | ChatSession, ChatMessage | 前端展示 | CRUD 操作 |
| **状态数据** | checkpoints, checkpoint_blobs | Agent 状态 | PostgresSaver 自动管理 |

**优势**：
- 前端查询不受 Agent 状态影响
- Agent 状态管理完全自动化
- 两者独立扩展，互不干扰

### 3.2 FastAPI 规范

```python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session
from typing import List

router = APIRouter(prefix="/api/chat", tags=["chat"])

@router.get(
    "/sessions/{session_id}",
    response_model=SessionResponse,
    summary="获取单个会话",
    description="根据 ID 查询会话信息"

def get_session_endpoint(
    session_id: str,
    db: Session = Depends(get_db)
```

#### 3.3.2 CRUD 操作

```python
from typing import List, Optional
from sqlalchemy.orm import Session

def get_session(db: Session, session_id: str) -> Optional[ChatSession]:
    """获取单个会话"""
    return db.query(ChatSession).filter(ChatSession.id == session_id).first()

def get_sessions(db: Session, skip: int = 0, limit: int = 100) -> List[ChatSession]:
    """获取会话列表"""
    return db.query(ChatSession).order_by(ChatSession.updated_at.desc()).offset(skip).limit(limit).all()

def create_session(db: Session, session: SessionCreate) -> ChatSession:
    """创建会话"""
    db_session = ChatSession(**session.model_dump())
    db.add(db_session)
    db.commit()
    db.refresh(db_session)
    return db_session

def update_session(db: Session, session_id: str, session_update: SessionUpdate) -> Optional[ChatSession]:
    """更新会话"""
    db_session = db.query(ChatSession).filter(ChatSession.id == session_id).first()
    if not db_session:
        return None

    # 只更新提供的字段
    update_data = session_update.model_dump(exclude_unset=True, exclude_none=True)
    for field, value in update_data.items():
        setattr(db_session, field, value)

    db.commit()
    db.refresh(db_session)
    return db_session

def delete_session(db: Session, session_id: str) -> bool:
    """删除会话"""
    db_session = db.query(ChatSession).filter(ChatSession.id == session_id).first()
    if not db_session:
        return False

    db.delete(db_session)
    db.commit()
    return True
```

**关键点**：
- 返回类型使用 `Optional[T]`
- 创建操作返回模型实例
- 更新操作使用 `model_dump(exclude_unset=True, exclude_none=True)`
- 删除操作返回布尔值
- 使用 `order_by()` 排序

```typescript
// composables/useChatStream.ts
import { ref } from 'vue'
import { chatApi } from '@/api/chat'
import type { Message } from '@/types'

export function useChatStream() {
  const isLoading = ref(false)
  const error = ref<string | null>(null)

  const sendMessage = async (
    message: string,
    sessionId: string,
    onChunk: (chunk: string) => void,
    onComplete: (message: Message) => void
  ) => {
    isLoading.value = true
    error.value = null

    try {
      await chatApi.stream(message, sessionId, {
        onChunk,
        onComplete
      })
    } catch (err) {
      error.value = err instanceof Error ? err.message : '发送消息失败'
    } finally {
      isLoading.value = false
    }
  }

  return {
    isLoading,
    error,
    sendMessage
  }
}
```

### 4.2 Pinia 规范

#### 4.2.1 Store 定义

使用 Setup Stores：

```typescript
// stores/sessions.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { sessionsApi } from '@/api/sessions'
import type { Session } from '@/types'

export const useSessionsStore = defineStore('sessions', () => {
  // State
  const sessions = ref<Session[]>([])
  const currentSession = ref<Session | null>(null)
  const isLoading = ref(false)

  // Getters
  const sortedSessions = computed(() =>
    [...sessions.value].sort((a, b) =>
      new Date(b.updated_at).getTime() - new Date(a.updated_at).getTime()
    )
  )

  // Actions
  const loadSessions = async () => {
    isLoading.value = true
    try {
      sessions.value = await sessionsApi.list()
    } finally {
      isLoading.value = false
    }
  }

  const selectSession = (session: Session) => {
    currentSession.value = session
  }

  return {
    sessions,
    currentSession,
    isLoading,
    sortedSessions,
    loadSessions,
    selectSession
  }
})
```

**关键点**：
- 使用 Setup Stores 语法
- State 使用 `ref`
- Getters 使用 `computed`
- Actions 使用普通函数
- Refs 自动解包，不需要 `.value`

### 5.1 表设计原则

#### 5.1.1 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| **表名** | 小写，下划线分隔，复数 | `chat_sessions`, `chat_messages` |

| **布尔值** | `is_` 前缀 | `is_active`, `is_deleted` |

#### 5.1.2 字段类型选择

| 数据类型 | PostgreSQL 类型 | Python 类型 | 说明 |
|---------|----------------|------------|------|
| **主键** | VARCHAR(36) / UUID | str | 使用 UUID 字符串 |
| **外键** | VARCHAR(36) / UUID | str | 与关联表主键一致 |
| **短文本** | VARCHAR(n) | str | 限制长度的文本 |
| **长文本** | TEXT | str | 不限制长度 |
| **JSON** | JSONB / TEXT | dict / str | PostgreSQL 用 JSONB，其他用 TEXT |
| **布尔值** | BOOLEAN | bool | true/false |
| **整数** | INTEGER | int | 整数 |
| **小数** | DECIMAL | Decimal | 精确小数 |
| **时间** | TIMESTAMP | datetime | 带时区 |

### 5.2 关系设计

#### 5.2.1 一对多关系

```python
class ChatSession(Base):
    # 一对多关系
    messages = relationship(
        "ChatMessage",
        back_populates="session",
        cascade="all, delete-orphan",  # 级联删除
        lazy="select"  # 懒加载
    )

class ChatMessage(Base):
    # 外键
    session_id = Column(String(36), ForeignKey("chat_sessions.id", ondelete="CASCADE"))
    # 反向关系
    session = relationship("ChatSession", back_populates="messages")
```

**级联策略**：
- `all, delete-orphan` - 删除父对象时自动删除子对象
- `save-update` - 默认，保存父对象时自动保存子对象
- `merge` - 合并父对象时自动合并子对象
- `refresh-expire` - 刷新父对象时使子对象过期
- `expunge` - 父对象被逐出时会话时逐出子对象

```python
from langchain_deepseek import ChatDeepSeek
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware
from langchain_community.agent_toolkits.load_tools import load_tools
from langgraph.checkpoint.postgres import PostgresSaver
from psycopg_pool import ConnectionPool

class ResearchAgentService:
    def __init__(self):
        self.agent = None
        self._initialize_agent()

    def _initialize_agent(self):
        """初始化 Agent"""
        # 1. 初始化 LLM
        llm = ChatDeepSeek(
            model=settings.deepseek_model,
            temperature=settings.agent_temperature,
            max_tokens=settings.agent_max_tokens,
            timeout=None,
            max_retries=2,
            api_key=settings.deepseek_api_key,
            base_url=settings.deepseek_base_url,
        )

        # 2. 加载工具
        tools = load_tools(["arxiv"], llm=llm)

        # 3. 创建系统提示
        system_prompt = """你是一个专业的研究助手..."""

        # 4. 创建连接池
        self.conn_pool = ConnectionPool(
            conninfo=settings.database_url,
            min_size=1,
            max_size=10,
            timeout=30
        )

        # 5. 创建 PostgresSaver
        self.checkpointer = PostgresSaver(self.conn_pool)
        try:
            self.checkpointer.setup()
        except Exception:
            pass  # 表已存在

        # 6. 配置摘要中间件
        summarization_middleware = SummarizationMiddleware(
            model=llm,
            trigger=("tokens", 4000),
            keep=("messages", 20)
        )

        # 7. 创建 Agent
        self.agent = create_agent(
            model=llm,
            tools=tools,
            system_prompt=system_prompt,
            checkpointer=self.checkpointer,
            middleware=[summarization_middleware]
        )
```

### 7.3 工具调用处理

#### 7.3.1 提取工具调用

```python
from langchain_core.messages import AIMessage, ToolMessage

def extract_tool_calls(messages: List) -> List[dict]:
    """提取工具调用信息"""
    tool_calls = []

    for msg in messages:
        if isinstance(msg, AIMessage) and hasattr(msg, "tool_calls") and msg.tool_calls:
            for tool_call in msg.tool_calls:
                try:
                    tool_info = {
                        "name": tool_call["name"] if tool_call["name"] else "",
                        "args": dict(tool_call["args"]) if tool_call["args"] else {},
                        "id": tool_call["id"] if tool_call["id"] else ""
                    }
                    # 只保存有效的工具调用
                    if tool_info["name"] and tool_info["id"]:
                        tool_calls.append(tool_info)
                except (KeyError, TypeError):
                    continue

    return tool_calls
```

**关键点**：
- 只保存有效的工具调用（有 `name` 和 `id`）
- 使用 try-except 处理异常
- 对话历史不恢复 `tool_calls`，让 Agent 重新决策

## 11. 常见问题与解决方案

### 11.1 PostgresSaver 相关问题

#### 问题 1：`'_GeneratorContextManager' object has no attribute`

**原因**：`PostgresSaver.from_conn_string()` 返回上下文管理器

**解决方案**：
```python
# ❌ 错误
self.checkpointer = PostgresSaver.from_conn_string(DB_URL)

# ✅ 正确
from psycopg_pool import ConnectionPool
self.conn_pool = ConnectionPool(conninfo=DB_URL)
self.checkpointer = PostgresSaver(self.conn_pool)
```

#### 问题 2：Agent 不记得之前的对话

**原因**：未传递 `config` 参数

**解决方案**：
```python
config = {"configurable": {"thread_id": str(session_id)}}
result = agent.invoke({"messages": [...]}, config=config)
```

#### 问题 3：`checkpointer.setup()` 报错

**原因**：表已存在

**解决方案**：
```python
try:
    self.checkpointer.setup()
except Exception as e:
    logger.info(f"检查点表已存在: {e}")
```

### 11.2 数据库相关问题

#### 问题 1：N+1 查询问题

**解决方案**：使用 `joinedload`
```python
from sqlalchemy.orm import joinedload

sessions = db.query(ChatSession).options(
    joinedload(ChatSession.messages)
).all()
```

#### 问题 2：连接池耗尽

**解决方案**：增加 `max_size` 或优化查询
```python
conn_pool = ConnectionPool(
    conninfo=DB_URL,
    min_size=2,
    max_size=50,  # 增加最大连接数
    timeout=60
)
```

### 11.3 前端相关问题

#### 问题 1：Pinia Refs 自动解包错误

**解决方案**：
```typescript
// ❌ 错误
messagesStore.messages.value.push(item)

// ✅ 正确
messagesStore.messages.push(item)
```

#### 问题 2：流式输出卡住

**解决方案**：确保调用 `clearStreamingMessage()`
```typescript
const onComplete = () => {
  clearStreamingMessage()
  loadMessages(sessionId)
}
```
