# Chat UI Refresh Design

**日期：** 2026-04-19  
**范围：** `frontend` 聊天界面的视觉与响应式优化，不调整业务功能与交互逻辑。

## 目标

将现有前端聊天界面优化为更现代、简洁明快、友好，并能自适应不同终端尺寸的 Chat Workspace。

## 已确认决策

- 视觉方向采用 `方案 A：明亮卡片式 Chat Workspace`
- 桌面端保留双栏：左侧会话列表，右侧聊天区
- 移动端改为顶部工具栏 + 会话抽屉
- 不更换现有功能与逻辑
- 不引入新依赖，不做大规模重构

## 设计原则

- 最小改动：仅触达表现层和必要的本地 UI 状态
- 保持现有信息结构与操作路径
- 优先提升层级、留白、可读性、响应式体验
- 统一主题 token，减少旧样式中偏紫与玻璃感的堆叠

## 视觉系统

- 主题从偏紫玻璃感调整为浅冷白 + 蓝青点缀
- 主色用于发送按钮、选中态、焦点态、流式状态
- 辅助色用于局部高亮、渐变和轻提示
- Surface 保持明亮纯净，背景采用轻微渐变增强层次
- 阴影改为轻量卡片层级，减少 glow 感
- 正文与说明文字采用更稳定的深蓝灰 / 灰蓝体系

## 布局策略

### 桌面端

- 保留左栏会话区，但整体更轻、更接近导航面板
- 右侧聊天区作为主工作区，强化顶部栏、消息区、输入区层次
- 输入区采用卡片式 composer 风格
- 消息区收束最大阅读宽度，减少超宽屏阅读疲劳

### 移动端

- 增加顶部栏中的会话抽屉开关
- 会话列表由侧栏切换为抽屉，不引入滑动手势
- 聊天主体全宽铺开，但为消息与输入保留安全边距
- 输入区固定在底部安全区域内，按钮与开关满足触控尺寸

## 组件级改造

- `src/style.css`：重建颜色、阴影、按钮、输入框、Markdown 样式 token
- `src/views/ChatView.vue`：增加移动端抽屉、本地显隐状态、重组主布局
- `src/components/SessionList.vue`：优化列表区密度与空状态
- `src/components/SessionItem.vue`：优化选中态、删除按钮、信息层级
- `src/components/MessageList.vue`：优化消息容器宽度、空列表视觉和滚动区留白
- `src/components/MessageItem.vue`：统一用户/AI/错误/中断/流式状态卡片体系
- `src/components/EmptyState.vue`：简化欢迎态，避免装饰过重
- `src/components/ToggleSwitch.vue`：细化现代工作台风格，与新主题统一

## 非目标

- 不修改 API、store、数据结构、发送逻辑、流式逻辑
- 不新增 dark mode
- 不增加前端测试框架或 UI 库
- 不重构与本次 UI 无关的模块

## 验证方式

- 运行 `npm run build:check`
- 检查桌面端与移动端布局是否可用
- 检查会话抽屉、消息列表、输入区、状态样式是否正常

## 风险与处理

- 当前前端存在一个与 UI 无关的类型断言问题，会阻塞构建验证
- 为保证可验证交付，允许一并做最小类型修正，但不改变运行逻辑
