120JPH涂装车间AI助手 · 系统架构设计

基于 Vue 3 + FastAPI + LangGraph + Vector RAG 的高精准度 Text-to-SQL 涂装车间智能数据分析系统

大模型 Text-to-SQL 执行纪律 & 约束

  • • 只读查询红线：严禁执行任何 INSERT、UPDATE、DELETE 等 DML 操作。
  • • 强制技能绑定：每次执行 sql_db_query 必须传入 required_skill 参数声明对应领域。
  • • 非标时间清洗：对 DATE_EVT 等字段自动包装 `STR_TO_DATE` 函数，解决字符串比对错误。
  • • 智能防溢截断：当查询结果过大触及截断时，不基于截断数据做二次计算，主动提醒通过 CSV 导出。

涂装车间核心业务领域技能 (Domains)

  • • 涂装缺陷智能分析 (Defect Analysis)：注入表结构表头及对应中文翻译、缺陷代码逻辑，生成直观报表。
  • • 车间过站物流追踪 (Vehicle Logistics)：锁定车辆在 Rollerbed 区域的物理移动轨迹、过站时刻分析。
  • • 历史 SQL 范例检索 (RAG Tool)：使用 Milvus 混合检索（稠密+BM25稀疏）与 Rerank 机制，提取高置信度历史正确 SQL 范例。
  • • 双指标图表生成 (build_chart_artifact)：可为分类对比、时间趋势等数据主动生成可视化 Chart。

拦截器流水线 & 高可用配置

  • • RAG Middleware：独立模块解耦设计，集成 Milvus Hybrid + RRF 融合与精排，支持自动防灾回退（PGVector）。
  • • Summarization Middleware：监测上下文 Token 规模，超出阈值自动触发会话摘要以防超出大模型上限。
  • • Context Warning Middleware：对 Llama.cpp 端点进行异步 Token 估算，防止高频率 HTTP 400 级崩溃。
  • • 双持久化快速自愈：即使脱离 LangGraph 托管平台，本地亦可激活 `AsyncPostgresSaver` 稳定记录 checkpoints。
