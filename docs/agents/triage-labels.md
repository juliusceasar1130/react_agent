# Triage Labels

技能在处理问题时使用五个标准分拣角色。本文件将这些角色映射到本仓库实际使用的标签字符串。

## 标签映射关系

| 角色 (Role) | 标签字符串 (String) | 说明 |
|------|--------|-------------|
| `needs-triage` | **待评估** | 新提交的问题，需要维护者评估。 |
| `needs-info` | **需要反馈** | 等待报告者提供更多信息。 |
| `ready-for-agent` | **AI可处理** | 描述清晰，智能体可以直接开始处理。 |
| `ready-for-human` | **人工待办** | 需要人工介入或由人类开发者完成。 |
| `wontfix` | **暂不处理** | 决定不处理该问题。 |

## 使用规则

当技能提到一个角色（例如 "apply the AFK-ready triage label"）时，请使用上表中的中文标签字符串。不用创建英文标签的副本。
